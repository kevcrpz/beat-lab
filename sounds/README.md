# Sounds

Upload your own sounds here: **Add file** → **Upload files**. Then use one
in a song with a line near the top, like:

```text
sound: cowbell = sounds/cowbell.wav
```

Keep sounds short (a second or two), and name them in lowercase with
dashes, like `dog-bark.wav`. The **Record a sound** button on your live link
makes a ready-to-upload `.wav` file.

`cowbell.wav` was made from scratch for this project (two buzzy tones that
fade fast, like an old drum machine), so it's free to use.
